# I64-S1 WP-B1 — Federated-Learning Contract Address Projection

The five federated-learning contracts joined the chain-40204 surface *after* the
last reroll, so they have no entry in the broadcast-confirmed address table. This
doc records their **deterministic CREATE2 projection** and the exact inputs that
fix each address, so the reroll ceremony can reproduce them byte-for-byte and the
dry-run table diff is a clean "additions only."

Generated by `forge script script/DeployFederatedLearning.s.sol` simulated against
the genesis Arachnid factory `0x4e59b44847b379578588920cA78FbF26c0B4956C`.

## Determinism contract — the ceremony MUST hold ALL of these

CREATE2 address = `keccak256(0xff ++ factory ++ salt ++ keccak256(init_code))[12:]`,
and `init_code = creationCode ++ abi.encode(constructor_args)`. Salt is
`Salts.salt("<name>") = keccak256(abi.encodePacked("citrate.v1.", "<name>"))`
(no VERSION bump → existing 45 addresses untouched). Therefore the constructor
args are determinism inputs. To land the addresses above, the ceremony must use:

1. **deployer = `0x4250675F9015E65fC866F3a373F82bb9DFc000c6`** (the canonical
   genesis deployer). Four of the five embed this address (directly via
   `KYCRegistry(deployer)`, transitively via the IPFS `kyc` arg). A different
   deployer moves four of the five addresses. *(Verified: re-simulating with a
   different sender moved KYC/V2/V3/Pipeline and left only AggregationChallenge
   fixed.)*
2. **governance = deployer** (i.e. `GOVERNANCE` env unset). `ComputePoolPipeline`
   bakes `governance` into init_code. If governance is intended to be a *separate*
   address (e.g. TreasuryGovernor `0x4cd381…`), set `GOVERNANCE` and **re-run the
   dry-run** — the ComputePoolPipeline address WILL change, and this table must be
   regenerated before the ceremony.
3. **teeRegistry = `0x4dF26aae3619f449a142d237ed818Ebf7C186Ed5`** (the canonical, LIVE
   40204 TEEAttestationRegistry). ⚠️ CORRECTED 2026-08-27: this doc previously listed
   `0xc1c0d858…E777E`, which has NO code on-chain — that stale pin wired ComputePoolPipeline to a dead
   registry. The canonical TEE is `0x4dF26aae…` (has bytecode; = book / DeployTEEAttestationRegistry).
4. **Economic params exactly as pinned** in `DeployFederatedLearning.s.sol` (see
   below). These fix both the protocol economics AND the addresses.
