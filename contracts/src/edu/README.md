Planned contents include:

- `InstitutionalVault`
- `ClassroomClusterV1`
- `BudgetAllocation`
- `CashoutRequest`

This directory exists now as a scaffold only. Contract code should not be added until the current schema, TLA+, and benchmark gates are satisfied.
